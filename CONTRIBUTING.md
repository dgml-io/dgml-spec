# Contributing to DGML Spec

DGML is an open initiative founded by Docugami and Inveniam. This repository
contains the DGML format specification. The Python reference implementation
lives in [dgml-io/dgml](https://github.com/dgml-io/dgml).

## How to contribute

### Ask a question or start a discussion
Open a [GitHub Discussion](../../discussions). This is the right place for
questions about the spec, ideas for new features, or use cases you would like
the format to support.

### Report a problem with the spec
Open a [GitHub Issue](../../issues) if you find an error, ambiguity, or
inconsistency in the specification.

### Propose a change
1. Open an Issue or Discussion first to describe what you want to change and why
2. Once there is consensus, submit a Pull Request with the change
3. Small fixes (typos, clarifications) can go straight to a PR

### Contribute to the samples
The `samples/` folder contains reference DGML documents. If you have a
real-world document type that would make a useful addition, open an Issue
to discuss it first.

## Contributor License Agreement (CLA)

Before your Pull Request can be merged, you must sign the Apache Individual
Contributor License Agreement. The CLA bot will prompt you automatically
when you open your first PR. This is a one-time requirement.

## Governance

DGML is governed as an open standard. A steering committee will be established
over time to guide the evolution of the format, with representation from
contributors and adopters.
